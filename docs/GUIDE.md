# ☕ coffee game 사용 설명서

## 접속
- 웹: https://kodaehan010-debug.github.io/coffee-game/
- 내 PC 실행: `start.bat` 더블클릭 → 브라우저 자동 열림 / 종료: `stop.bat`

## 사용 순서
1. **홈**: 참가자 이름 입력 (쉼표로 여러 명 한 번에, 최대 30명)
2. **당첨 인원** 선택 (1~3명)
3. **게임 고르기** → 4종 중 선택 또는 🎲 랜덤 게임
4. **결과** 화면: 당첨자 표시, 메뉴·금액 메모(선택) 저장

## 게임 규칙

| 게임 | 진행 방법 |
|---|---|
| 🎡 룰렛 | [돌리기] → 멈춘 칸 당첨. 당첨 인원만큼 반복(당첨자 제외) |
| 🃏 제비뽑기 | 차례인 사람이 카드 1장 선택. [남은 사람 자동 배정] 가능 |
| 🪜 사다리타기 | 이름 클릭 → 경로 표시. [전체 결과 보기] 가능 |
| 💣 폭탄 돌리기 | [시작] → 화면 속 이름의 사람이 [넘기기] 클릭(랜덤 전달). 5~15초 사이 폭발 시 들고 있던 사람 당첨 |
| 🏇 경마 | [출발] → 랜덤 경주. 늦게 들어온 사람 당첨 |
| 🔢 숫자 업다운 | 1~100 비밀 숫자를 차례로 추측(UP/DOWN 안내). 맞힌 사람 당첨 |
| ⚡ 반응속도 | 한 명씩: 화면 누르고 기다리다 "지금!"에 클릭. 가장 느린 사람 당첨, 신호 전 클릭은 부정출발(최하위). ⚠️ 실력 게임 |

- 20명 초과 시 룰렛은 번호로 표시 + 아래 번호표
- 사다리는 인원이 많으면 좌우 스크롤

## 기록
- ⚠️ 기록은 **이 PC의 이 브라우저에만** 저장 (다른 PC와 공유 안 됨)
- 백업: [기록] → 내보내기(JSON 파일) / 다른 PC에서 가져오기
- 통계: [기록] 화면 위쪽 (총 게임·총 금액·사람별 당첨 횟수/당첨률/결제 금액, 공동 당첨 시 금액 1/n)
- 효과음 켜기/끄기: [설정]

## 엑셀 명단 / 즐겨찾기

- 엑셀 형식: `.xlsx`, 첫 시트, 1행 머리글 `팀` / `이름` (팀명·소속·부서, 성명 도 인식)
  - 머리글 없으면 A열=팀, B열=이름 으로 처리
  - 앞뒤 공백 자동 정리, 같은 팀 같은 이름 중복 제거
- 사용 순서
  1. 참가자 입력 화면 > 엑셀 명단 > 파일 선택
  2. 팀 선택 → 참가자 체크 (전체 선택 가능)
  3. 확인 → 참가자 목록에 추가 (최대 30명, 중복 제외)
- 동명이인(다른 팀 같은 이름): `이름(팀)` 으로 표시
- 즐겨찾기: 현재 참가자 목록을 이름 붙여 저장 → 이름 클릭 시 목록 교체, × 로 삭제
- 명단·즐겨찾기는 이 브라우저에만 저장 (서버 전송 없음)

## 명단 관리 ([설정] > 명단 관리)

- 팀 탭(전체/팀별) + 검색(이름·팀)으로 조회, 인원 수 표시
- 사람 추가: 팀 선택(또는 새 팀 입력) + 이름 → 추가 (같은 팀 같은 이름 거부)
- 행별 삭제(확인창), 엑셀로 명단 바꾸기, 기본 명단으로 되돌리기
- 기본 명단: `src/data/roster.local.json` (git 제외, 실명 포함)
  - 재생성: `project/frontend` 에서 `python scripts/make-roster.py` (원본 `docs/users.xlsx`, openpyxl 필요)
  - 파일 없으면(배포 사이트) 빈 명단으로 시작

## 당첨 보정 (공정성)
- 기록상 당첨이 많은 사람일수록 당첨 확률 낮춤 (참가자 중 최소 당첨 횟수 대비 차이 d → 확률 비중 1/(1+d))
- 적용: 룰렛, 제비뽑기, 폭탄 돌리기
- 미적용: 사다리·경마(순수 무작위), 업다운·반응속도(진행 방식상 불가)
- 기록을 지우면 보정도 초기화
